## 不再跟踪某个已经提交的文件

```sh
# --skip-worktree     更强大，适合"文件已提交但本地会频繁修改"的场景，git pull/merge 不会轻易覆盖
# --assume-unchanged  主要用于性能优化，git 操作可能会重置这个标志

# 只看修改的文件:
git status --porcelain | grep '^ M'

# 标记:
git update-index --skip-worktree <文件路径>
git update-index --assume-unchanged <文件路径>

# 查看哪些文件被标记：
git ls-files -v | grep '^S'  # skip-worktree
git ls-files -v | grep '^h'  # assume-unchanged

# 取消标记：
git update-index --no-skip-worktree <文件>
```
